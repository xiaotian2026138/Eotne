# Eotne

Eotne 是一个极简、轻量的浏览器，它没有广告，没有追踪器，保护用户隐私，数据全部存在本地，不用担心数据被泄露。

## 核心功能
- **多标签浏览**：流畅切换，长标题自动省略。
- **自定义快捷方式**：支持添加、删除、重命名自己喜欢的网站。
- **纯净安全**：无内置广告，无后台数据上传。
- **后台下载管理**：关掉网页也不影响后台下载，文件存入本地下载目录。
- **中文错误页**：友好的错误提示，告别白屏和英文报错。

## 如何下载与安装
1. 点击页面右侧的 **Releases** 标签。
2. 找到最新的版本（如 `v0.7.0`）。
3. 点击 **Assets** 下方的 `Eotne.Setup.0.7.0.exe` 下载。
4. 下载完成后，双击安装包即可使用（无需配置任何环境）。
