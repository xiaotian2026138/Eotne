# Eotne

Eotne 是一个极简、轻量的浏览器，它没有广告，没有追踪器，保护用户隐私，数据全部存在本地，不用担心数据被泄露。

## 核心功能
- **多标签浏览**：流畅切换，长标题自动省略。
- **自定义快捷方式**：支持添加、删除、重命名自己喜欢的网站。
- **纯净安全**：无内置广告，无后台数据上传。
- **后台下载管理**：关掉网页也不影响后台下载，文件存入本地下载目录。
- **中文错误页**：友好的错误提示，告别白屏和英文报错。
- **无痕模式**：点击确认弹窗，进行后不保存历史记录。
- **长按时间显示切换**：长按选择切换12小时制和24小时制，不用担心看不懂时间。

## 如何下载与安装
1. 点击页面右侧的 **Releases** 标签。
2. 找到最新的版本。
3. 点击 **Assets** 下方，找到`Eotne.Setup.x.x.x.exe`格式下载。(根据你选择的版本为准)
4. 下载完成后，双击安装包即可使用（无需配置任何环境）。

## 双击run.bat需安装什么环境和依赖
如果双击run.bat，请务必确保你是否有Node环境和依赖，如果缺少其中一个，很可能会无法运行，导致报错。

官网链接：nodejs.org

依赖：npm install

如果报错，请在执行npm install命令之前，依次输入：

npm config set registry https://registry.npmmirror.com/

npm config set ELECTRON_MIRROR https://npmmirror.com/mirrors/electron/
